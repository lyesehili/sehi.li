Course project · EPFL CS-233

Machine Learning for Medical Classification

Experiments in heart disease prediction and skin lesion classification using tabular records and dermoscopic images.

Status
Completed
Technologies
Python, PyTorch

Context

I worked on this project with friends for EPFL’s Introduction to Machine Learning course. Both datasets were imbalanced, so we compared overall accuracy with macro F1, which gives each class equal weight.

Heart disease classification

We implemented logistic regression, k-nearest neighbors, and k-means from scratch and compared them on 297 records with five heart disease labels. We tuned hyperparameters using five-fold cross-validation and evaluated on a held-out test set.

Read the heart disease report (PDF)

Skin lesion classification

We compared multilayer perceptrons and convolutional neural networks on 9,012 DermaMNIST images across seven classes. In our CNN comparison, class weighting raised macro F1 from 0.364 to 0.423, while overall accuracy fell from 70.3% to about 63%. The weighted model scored better when each class counted equally, but made fewer correct predictions overall.
